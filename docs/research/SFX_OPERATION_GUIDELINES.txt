# 범용 SFX 프리셋 운용 지침
버전: 1.0
적용 대상: 대본 작성 AI / Codex 자동화 / LongTube 렌더 / FFmpeg 후처리
기준 프리셋 소스: 범용_SFX_프리셋_라이브러리.txt

======================================================================
1. 목적
======================================================================

이 지침은 고대·중세·근세·근대·현대 콘텐츠 전반에서 효과음(SFX), 환경음(AMB), 편집 강조음, 정적을 일관된 방식으로 선택·기록·재사용하기 위한 기준이다.

효과음은 장면을 설명하는 장식이 아니라 공간, 시대, 행동, 긴장, 명대사의 타이밍을 강화하는 연출 요소로 사용한다.

대본 작성 AI는 반드시 '범용_SFX_프리셋_라이브러리.txt'의 ID를 우선 사용한다.

======================================================================
2. 절대 원칙
======================================================================

1) 대본에 자유문장으로만 효과음을 쓰지 않는다. 가능한 경우 반드시 등록된 SFX ID를 사용한다.

2) 효과음 ID는 프리셋 라이브러리와 정확히 일치해야 한다. 존재하지 않는 ID를 임의로 만들지 않는다.

3) 프리셋에 없는 효과음이 반드시 필요할 때만 신규 생성을 허용한다. 신규 생성 시:
   - 기존 ID 체계를 따른다.
   - 중복 여부를 먼저 확인한다.
   - 생성 프롬프트를 함께 기록한다.
   - 생성 완료 후 로컬 프리셋으로 등록할 수 있게 한다.

4) 대사가 항상 우선이다. SFX가 대사의 명료도를 방해하면 SFX 볼륨을 낮추거나 제거한다.

5) 한 컷에 효과음을 과도하게 넣지 않는다. 기본적으로:
   - 환경음 0~1개
   - 행동효과음 0~2개
   - 강조효과음 0~1개
   를 권장한다.

6) 시대에 맞는 효과음을 선택한다. 고대 장면에 자동차·전자음·현대 총기음을 넣지 않는다. 현대 장면에 필요 없는 고대 제례음·전쟁북을 임의로 넣지 않는다.

7) H3, KREA2, ElevenLabs와 역할을 분리한다.
   - KREA2: 정지 이미지
   - MiniMax H3: 영상 움직임
   - ElevenLabs: 음성
   - SFX: 후처리 오디오

8) MiniMax H3에 효과음 생성을 요구하지 않는다. SFX는 후처리 단계에서 별도 믹싱한다.

9) 실제이미지·지도·유물 설명 컷은 SFX를 최소화한다. 필요하면 AMB_MINIMAL 또는 해당 장소의 잔잔한 환경음만 사용한다.

10) 정적도 하나의 연출 도구로 취급한다. 명대사·죽음·배신·반전 직전에는 효과음을 더 넣기보다 SILENCE 프리셋과 덕킹을 우선 고려한다.

======================================================================
3. 대본양식 입력 규칙
======================================================================

대본양식의 SFX 관련 열:

- 환경음 (AMB_ID)
- 행동효과음 (SFX_ID)
- SFX 시작/타이밍(초)
- SFX 볼륨(dB)
- SFX 연출 / 덕킹

작성 규칙:

[환경음 (AMB_ID)]
장면 전체를 받치는 환경음을 1개 선택한다.
예:
AMB_FOREST_NIGHT_01
AMB_MODERN_CITY_DAY_01
AMB_ANCIENT_PALACE_NIGHT_01

[행동효과음 (SFX_ID)]
해당 컷의 핵심 행동에 필요한 효과음을 기록한다.
여러 개면 쉼표로 구분한다.
예:
SWORD_DRAW_01
DOOR_WOOD_SLAM_01, STEP_ARMOR_RUN_01

[SFX 시작/타이밍(초)]
컷 시작을 0.00초로 본다.
예:
0.00
1.20
3.80

여러 효과음이면:
SWORD_DRAW_01@1.20 / WAR_DRUM_SINGLE_01@4.70

[SFX 볼륨(dB)]
기본 권장:
- 주 환경음: -24~-16 dB
- 행동효과음: -18~-8 dB
- 강조효과음: -16~-6 dB
- TTS와 겹치는 강한 효과음은 더 낮춘다.

[SFX 연출 / 덕킹]
자연어로 자동 믹싱 지시를 기록한다.

예:
대사 시작 0.3초 전 환경음 -8dB 추가 감쇄, 대사 종료 0.5초 후 원복.
명대사 직전 0.5초 정적, 종료 0.2초 후 WAR_DRUM_SINGLE_01 1회.
칼 뽑는 소리는 화면 동작 시점과 정확히 맞춘다.

======================================================================
4. SFX ID 선택 순서
======================================================================

효과음을 선택할 때 아래 순서를 따른다.

1. 시대
2. 공간
3. 장면의 핵심 행동
4. 감정적 기능
5. 대사와의 충돌 여부

예시:

고대 궁궐 밤 + 왕의 밀담
→ AMB_ANCIENT_PALACE_NIGHT_01
→ 행동이 없으면 행동 SFX 생략
→ 반전 직전 필요 시 TENSION_DROP_01

현대 사무실 + 문서 던짐
→ AMB_MODERN_OFFICE_01
→ PAPER_STACK_01 또는 FIST_TABLE_01
→ 별도 드라마 효과음은 필요할 때만 추가

전투 직전 장군 명대사
→ BATTLE_ANCIENT_DISTANT_01
→ SILENCE_050
→ 명대사
→ WAR_DRUM_SINGLE_01

======================================================================
5. 환경음 운용 규칙
======================================================================

환경음은 컷마다 무조건 새로 시작하지 않는다.

같은 장소와 시간대가 이어지면 에피소드 타임라인에서 하나의 환경음을 연속 유지한다.

장면 전환 시에만:
- 크로스페이드
- 페이드아웃
- 새 환경음 진입
을 사용한다.

권장 크로스페이드:
0.3~1.5초

환경음은 장면의 존재감을 주되 대사보다 앞에 나오지 않는다.

======================================================================
6. 행동효과음 운용 규칙
======================================================================

행동효과음은 화면에서 실제로 보이는 행동과 동기화한다.

좋은 예:
- 칼을 뽑는 순간 SWORD_DRAW_01
- 문을 닫는 순간 DOOR_WOOD_SLAM_01
- 말이 급정지하는 순간 HORSE_STOP_01

나쁜 예:
- 화면에 없는 칼소리
- 단지 긴장된다는 이유로 무기 충돌음
- 행동보다 1~2초 먼저 나오는 효과음

행동음은 시각적 접촉 순간을 우선한다.

======================================================================
7. 드라마 강조음 운용 규칙
======================================================================

HIT_, RUMBLE_, WHOOSH_, TENSION_, REVEAL_ 계열은 현실 공간의 소리가 아니라 후반 편집용 효과다.

남발 금지.

권장 사용 지점:
- 중요한 사실 공개
- 배신 확인
- 왕 또는 핵심 인물 등장
- 죽음 확정
- 장면 전환
- 클리프행어
- 명대사 직후

같은 강조음을 반복 사용하면 단조로워지므로 에피소드 내 반복 횟수를 제한한다.

권장:
동일 강조 ID 최대 2~3회.

======================================================================
8. 명대사 SFX 규칙
======================================================================

명대사(Y) 컷은 효과음을 많이 넣지 않는다.

기본 우선순위:

1. 기존 환경음 유지
2. 명대사 직전 환경음 덕킹
3. 0.25~0.75초 정적
4. 명대사
5. 대사 종료 후 0.1~0.4초 여백
6. 필요하면 북·저음 HIT 1회

추천 조합:

[장군 결전]
BATTLE_* → SILENCE_050 → 대사 → WAR_DRUM_SINGLE_01

[왕의 선고]
AMB_* → 덕킹 → 대사 → HIT_LOW_01

[죽음]
AMB_WIND_GENTLE_01 → SILENCE_050 → 대사 → DEATH_HIT_01

[배신]
AMB_* → TENSION_DROP_01 → SILENCE_025 → 대사 → BETRAYAL_HIT_01

======================================================================
9. 대화 장면 SFX 규칙
======================================================================

DIALOGUE 그룹의 연속 대화에서는 효과음이 대화 리듬을 끊지 않게 한다.

같은 대화그룹 내 환경음은 유지한다.

상대가 말할 때:
- 환경음은 낮게 유지
- 필요 없는 행동효과음 추가 금지
- 청자 리액션을 위한 작은 의복·발걸음 정도만 허용

말싸움 장면에서 매 대사마다 HIT를 넣지 않는다.

강조음은 대화의 결정적 전환점 1회 정도로 제한한다.

======================================================================
10. 전투 SFX 규칙
======================================================================

전투 장면은 소리가 많아지기 쉬우므로 층위를 분리한다.

Layer 1: 원거리 전장 환경
예:
BATTLE_ANCIENT_DISTANT_01
BATTLE_WW2_01

Layer 2: 화면 속 핵심 행동
예:
SWORD_CLASH_01
RIFLE_SHOT_01
ARROW_RELEASE_01

Layer 3: 강조음
필요한 순간에만:
HIT_LOW_01
WAR_DRUM_SINGLE_01

대사 중에는 Layer 2와 3의 볼륨을 낮춘다.

======================================================================
11. 현대 총기·차량·기계 규칙
======================================================================

현대 장면은 시대 구분을 특히 엄격히 한다.

- 1930년대 자동차와 현대 자동차 소리를 구분한다.
- 초기 화약무기와 현대 소총을 구분한다.
- 증기기관차와 현대 열차를 구분한다.
- 현대 전자음은 고대/중세 장면에서 절대 사용하지 않는다.

정확한 기종 고증이 필요한 경우 범용 프리셋 대신 장면 전용 SFX를 별도 생성한다.

======================================================================
12. 신규 SFX 생성 규칙
======================================================================

프리셋에 없는 소리가 필요한 경우:

1. 기존 라이브러리에서 유사 ID 검색
2. 대체 가능하면 기존 프리셋 사용
3. 반드시 새 소리가 필요할 때 신규 ID 작성
4. 영문 생성 프롬프트 작성
5. 사람 말·음악·브랜드음 제거 조건 추가
6. 생성 후 ID.wav로 저장
7. 라이브러리에 추가

ID 규칙 예:

AMB_[장소]_[상태]_[번호]
SFX 또는 사물명_[행동]_[번호]

예:
AMB_FACTORY_NIGHT_02
ELEVATOR_EMERGENCY_STOP_01

신규 생성 공통 금지 문구:

No speech, no narration, no music, no logo sound, no branded sound,
no unrelated background elements.

======================================================================
13. 자동화 실행기(Codex 등) 적용 규칙
======================================================================

자동화 실행기는 대본을 읽고 다음 순서로 처리한다.

1. 환경음(AMB_ID) 확인
2. 로컬 SFX 폴더에서 ID.wav 검색
3. 존재하면 재사용
4. 없으면 프리셋 라이브러리에서 해당 ID의 생성 프롬프트 조회
5. 연결된 SFX 생성 도구/API가 있으면 생성
6. 생성한 WAV를 해당 ID로 캐시
7. SFX 시작/타이밍 값에 맞춰 배치
8. SFX 볼륨 적용
9. 덕킹 지시 적용
10. TTS와 환경음·효과음 믹싱
11. 최종 영상과 결합

Codex 자체가 직접 음향을 생성한다고 가정하지 않는다. Codex는 선택·생성요청·파일관리·믹싱 자동화를 담당한다.

======================================================================
14. 믹싱 권장 기준
======================================================================

절대값이 아니라 출발점으로 사용한다.

TTS:
- 기준 0~-3 dB

환경음:
- 일반적으로 -24~-16 dB

행동효과음:
- 일반적으로 -18~-8 dB

강조효과음:
- 일반적으로 -16~-6 dB

대사와 겹칠 경우:
효과음과 환경음 추가 -4~-10 dB 덕킹

대사가 끝나면:
0.3~1.0초에 걸쳐 자연스럽게 원복

과도한 피크는 리미터로 제어한다.

======================================================================
15. 실제자료·지도 컷
======================================================================

지도, 유물, 유적, 실제 사진을 해설하는 컷은 정보 전달이 최우선이다.

권장:
AMB_MINIMAL
또는 장소 특성에 맞는 매우 낮은 환경음.

비권장:
HIT, WHOOSH, 총성, 칼소리 등 자극적인 효과음 남발.

단, 지도에서 전쟁 이동경로를 설명하는 등 명확한 연출 이유가 있을 때만 제한적으로 사용한다.

======================================================================
